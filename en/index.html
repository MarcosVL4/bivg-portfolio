What I do

In my job I do both: I keep the systems running and I make use of their data. Knowing both sides removes a middleman: whoever looks after the server knows what data it holds and how to turn it into a report.

Reports and data models
Star schemas, DAX measures and loads from SQL Server, so the numbers add up and the report opens fast. Row-level security when each person should only see their own data.

Power BI, DAX, Power Query, SQL Server, T-SQL, SSIS.

Systems administration
Linux and Windows Server machines, virtualisation and containers. Set-up and maintenance, domains and certificates, remote access over VPN, single sign-on, firewalls, encrypted off-site backups with a recovery plan, and monitoring with alerts when something goes down.

Linux, Windows Server, PowerShell, Proxmox, Docker, Traefik, Cloudflare, Tailscale.

Process automation
Invoices, receipts and repetitive tasks that process themselves. AI reads and classifies where it helps, and a person reviews before anything is saved.

n8n, Python, PowerShell, REST APIs, AI models.

Custom applications
Internal tools that replace the shared spreadsheet: with users and permissions, usable from a phone, and storing data ready for analysis.

Next.js, TypeScript, React, Rust with Axum, PostgreSQL, SQLite.
